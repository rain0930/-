# 英雄聯盟答題（單人闖關＋排行榜）

不需要 npm install，只要有 Node.js 18 以上。

## 啟動
    node server.js

## 玩法
- 每個人用自己的手機，輸入暱稱後自己闖關，沒有倒數、不用等別人
- 選好選項後按「送出」，馬上看到對錯、得分和解說，再按「下一題」
- 每場隨機抽 10 題（含 3 題 ARAM）；選擇題的選項順序每次都會打亂
- 答完後進排行榜（記錄每個人的最佳成績），可以「再玩一次」重新抽題

## 題庫（questions.json）
- c: g 一般 / a ARAM（含 Mayhem 強化） / k 英雄技能
- t: choice 選擇、tf 是非、text 填空、order 排序、num 猜數字
- exp：答完後顯示的解說（選填）
- 圖片題：圖放進 public/images/，題目加 "img":"檔名.png"
- 影片題：mp4 放進 public/images/，題目加 "video":"檔名.mp4"；或用 YouTube："yt":"影片ID"
- 選擇題的正確答案寫在 "a"（選項索引，從 0 開始），不用擔心答案位置，遊戲會自動打亂

## 環境變數
PORT、PER（每場題數，預設 10）、ARAM_N（每場 ARAM 題數，預設 3）、IMG_N（每場圖片／影片題數，預設 2）

## 注意
遊戲資料存在伺服器記憶體裡，Render 免費方案休眠或重新部署後，排行榜會清空。
