# 英雄聯盟派對答題（獨立版）

不需要 npm install，只要有 Node.js 18 以上。

## 啟動
    node server.js

## 玩法（預設：不需要主持人）
1. 朋友用手機開網址，輸入暱稱加入
2. 任何一位玩家按「開始遊戲」就會開始
3. 每題倒數作答；所有在線玩家答完，或時間到，就自動公布答案；幾秒後自動下一題
4. 結束後任何人都可以按「再玩一次」（會重新隨機抽題）
- 想要大螢幕／主持人手動控制：開 /host?key=你的金鑰（選用，隨時可以提前公布或跳題）
- 設定 AUTO=0 可關閉自動進行，改成全部由主持人手動控制

## 自訂題目（questions.json）
- c: g 一般 / a ARAM；t: choice, tf, text, order, num
- 圖片題：把圖放進 public/images/，題目加 "img":"檔名.png"
- 影片題：把 mp4 放進 public/images/，題目加 "video":"檔名.mp4"（建議 20MB 以內、H.264 編碼）
- YouTube：題目加 "yt":"影片ID"（網址 watch?v= 後面那串）
- 可用 "time":40 指定這題的作答秒數（影片題預設 45 秒）
- 圖片／影片題可搭配任何題型，例如：
  {"c":"g","t":"choice","video":"clip1.mp4","q":"這段影片是哪位英雄的招式？","o":["A","B","C","D"],"a":0}

## 環境變數
PORT、PER（每場題數）、ARAM_N、IMG_N（每場圖片／影片題數）、QTIME（每題秒數，預設 25）、RTIME（公布答案停留秒數，預設 7）、AUTO、HOST_KEY

## 讓不同地方的朋友連線
部署到 Render 等雲端，啟動指令 node server.js。注意：免費方案閒置會休眠，且伺服器重啟後遊戲狀態會清空；影片檔案越大，載入越慢。
